Unitext

Turns plain text into Unicode typography on Discord — bold, script, zalgo, fullwidth, and 22 more.

View on GitHub Install
Styles Usage Install

Two ways to use it

Slash command

Full style list with live autocomplete previews — type a style, see what it looks like before you send.

/unitext font:bold message:Hello world

𝐇𝐞𝐥𝐥𝐨 𝐰𝐨𝐫𝐥𝐝

Answered ephemerally — only you see the confirmation, the channel just gets the styled text via webhook.

Chat trigger (instant)

No interaction round-trip, no "thinking…" state — the message is deleted and instantly reposted styled.

!bold Hello world

𝐇𝐞𝐥𝐥𝐨 𝐰𝐨𝐫𝐥𝐝

Short, natural aliases work too: !glitch, !bubble, !flip, !cursive, !b, !i…
